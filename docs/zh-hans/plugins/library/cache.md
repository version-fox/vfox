# Cache 标准库

`vfox` 为插件提供了一个简单的持久化键值缓存。在 Lua 脚本中，你可以使用 `require("vfox.cache")` 来访问它。

值以 JSON 形式保存，因此可以是字符串、数字、布尔值或由它们组成的 table。每次修改后缓存都会写入传给 `new` 的文件，
因此在多次运行之间依然有效。

**Usage**

```lua
local cache = require("vfox.cache")

local c, err = cache.new("/path/to/cache-file")

-- 第三个参数是以秒为单位的过期时间，-1（默认值）表示永不过期
c.set("key", { "a", "b" }, 3600)

local value = c.get("key") -- key 不存在或已过期时返回 nil

c.remove("key")
```

**限制**

当值过大或嵌套过深时，`c.set` 不会保存它，而是返回 `nil` 和错误信息：

- 嵌套超过 256 层的表会被拒绝。
- 单个值写出的 JSON 限制为 64 MiB。大小按编码后的形式保守估算，不会低于实际写出的大小：`<`、`>`、`&` 等被转义的字符（各占 6 字节）以及较长的键都按转义后的大小计算，被多次引用的表每次引用都会计算一次。估算值可能略高于实际大小（每个数组元素约多 1 字节，部分控制字符也会多算），因此略低于 64 MiB 的值也可能被拒绝。
- 字符串和表的键必须是有效的 UTF-8。

对普通数据，`json.encode` 没有深度或大小限制。唯一的限制针对被多次引用的表：重复引用所写出的值会被限制（约一百万个值或 64 MiB），这样一个小的共享表就不会膨胀成巨大的输出。
